# Trader Performance vs Market Sentiment Analysis

## Objective
Analyze relationship between Bitcoin market sentiment and trader performance.

## Methodology
- Data cleaning and timestamp alignment
- Feature engineering (PnL, win rate, trade frequency, risk level)
- Sentiment-based comparison
- Trader segmentation

## Key Insights
- Trader performance varies across sentiment regimes.
- Traders increase risk during Greed periods.
- High-risk traders show higher volatility.

## Strategy Recommendations
- Reduce exposure during Fear periods.
- Increase trading frequency during Greed.
- Apply segment-based trading strategies.

## How to Run
Install requirements and run notebook.
